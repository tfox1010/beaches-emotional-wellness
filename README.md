# Beaches Emotional Wellness

Static website for Tommy Fox, LMHC, designed for GitHub Pages.

## Preview
Enable GitHub Pages in Settings → Pages using `main` / `(root)`.

## Important: scheduling / login portal
The existing portal URLs use the `www.beachesemotionalwellness.com` hostname. **Do not change the domain DNS to GitHub Pages until the portal host routing is resolved.** Repointing it can break the schedule and login routes. Request a provider-hosted URL for both portals or use a separate hostname for the marketing site.

## Publishing checklist
Confirm phone number, address, fees, biographies, clinical claims, and patient disclosures with Tommy before switching the live domain. The public site must not collect protected health information.
